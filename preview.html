Recipe Finder 🥗

This is a React + Vite project. To run the full recipe search (including Spoonacular API and React Router), open the labs/lab9 folder in VS Code or CodeSandbox.

  1. In the lab9 folder, run npm install and npm run dev.
  2. Open the Vite localhost URL.
  3. Enter your Spoonacular API key, search and open recipe details.
  4. Navigate to the About us page.
